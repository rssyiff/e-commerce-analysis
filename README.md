# Proyek Analisis Data E-Commerce

## Deskripsi Proyek
Proyek ini bertujuan untuk menganalisis data transaksi e-commerce guna mengetahui tren pesanan, performa kategori produk, serta perilaku pelanggan berdasarkan metode pembayaran dan skor ulasan.

## Pertanyaan Bisnis
1. Bagaimana jumlah pesanan dan total nilai pembayaran berubah dari waktu ke waktu?
2. Kategori produk apa yang memiliki jumlah item terjual dan total nilai penjualan tertinggi?
3. Bagaimana distribusi metode pembayaran dan skor ulasan pelanggan?

## Dataset
Dataset yang digunakan adalah E-Commerce Public Dataset, yang terdiri dari data pelanggan, geolokasi, item pesanan, pembayaran, ulasan, pesanan, kategori produk, produk, dan penjual.

## Tools
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Cara Menjalankan Proyek
1. Pastikan Python dan library yang dibutuhkan sudah terpasang.
2. Pastikan folder `data` berada di direktori yang sama dengan notebook.
3. Buka `notebook.ipynb` menggunakan Jupyter Notebook.
4. Jalankan seluruh cell dari awal hingga akhir.

## Hasil Analisis
Analisis mencakup tren pesanan dan nilai pembayaran, performa kategori produk, serta distribusi metode pembayaran dan skor ulasan pelanggan.

## Kesimpulan
Hasil analisis menunjukkan adanya perubahan jumlah pesanan dan nilai pembayaran dari waktu ke waktu. Kategori produk dengan jumlah item terjual tertinggi berbeda dari kategori dengan total nilai penjualan tertinggi. Kartu kredit menjadi metode pembayaran yang paling banyak digunakan, sementara skor ulasan pelanggan didominasi oleh nilai 5.
